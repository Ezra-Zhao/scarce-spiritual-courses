## 为什么叫「稀缺」

有些属灵课程，英文世界里成书成课、体系完整，到了中文这边却几乎找不到成体系的材料：主内做生意与职场事工的训练课，市面上买不到中文版；异象异梦这么常见的信徒经历，华人教会里少有既守圣经、又讲操练的系统教导。本合集整理三套这样的材料：一套是全球公开资源的合集，一套是一门真实课程的目录导读，一套是一门中文教会稀有课程的讲章全文。整理的原则是先把家底盘清：有什么、缺什么，都如实写，不凑数、不夸大。

## 第 03 套的署名口径

《異象異夢入門與操練》是张迅弟兄的课程（成全事工 Helpers of Joy Ministries，2008 年主日学系列公开讲义）。本合集收的六篇，是赵广义把课程讲义编纂整理成的讲章：**原著张迅，赵广义编纂**——教导内容出自张迅弟兄，非编纂者原创。每篇讲章末尾都附编纂说明，经文引文采用和合本。

## 公开范围说明

本合集只公开三类内容：

1. **导读与目录**——整理者原创的介绍、纲要与课程地图；
2. **资源合集**——外部机构与课程的公开资源，附出处链接；
3. **编纂讲章**——经公开讲义编纂、且署名口径写明的讲章全文（第 03 套）。

不在公开之列的：他人课程的讲义与听课笔记全文（第 02 套只放目录与导读，想学请走课程方渠道），以及整理者个人的作业、操练与灵修记录（属个人隐私，不公开）。

## 怎么用这套合集

- 做生意或在职场的信徒：先读 01 的导读与经文根基，再按八个主题纲要自学；想看一门课的完整地图，看 02 的 32 讲目录。
- 对异梦异象有疑问、想操练的信徒：读第 03 套，按一到六讲的顺序，不要跳讲——护栏在前面，操练在后面。
- 教会带领与同工：三套都是现成的带领材料，导读可直接作开课介绍，目录可作查经与小组的进度表。
